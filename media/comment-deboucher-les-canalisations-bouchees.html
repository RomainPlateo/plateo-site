Comment déboucher les canalisations bouchées ?

Des canalisations bouchées ? Découvrez les facteurs responsables et les solutions pour les déboucher dans cet article !

Par Malaïka Hunt · 26 mai 2023 · 2 min de lecture

En tant que MJPM ou aidant professionnel vous vous êtes peut-être retrouvé dans une situation où un bénéficiaire se retrouve avec une ou plusieurs canalisations bouchées.

Les canalisations bouchées peuvent être une vraie source de problèmes pour un majeur protégé.

Non seulement cela peut causer des odeurs désagréables, mais cela peut aussi causer des dégâts des eaux, voire des inondations.

Il est donc important de savoir comment déboucher les canalisations bouchées.

WC

L'un des coupables les plus courants de canalisations bouchées dans la salle de bain est le papier toilette ou le sopalin jeté dans les toilettes en grande quantité.

Sachez que cela peut causer des problèmes à long terme.

En effet, lorsque ces objets se retrouvent dans la tuyauterie, ils rétrécissent le passage, ce qui peut conduire à un blocage complet.

Pour résoudre le problème, un débouchage simple, avec un furet, est souvent suffisant.

Il peut également arriver qu'un objet tombe accidentellement dans les toilettes, comme une brosse pour nettoyer les toilettes ou une brosse à cheveux.

Dans ce cas, il est recommandé de faire réaliser un passage caméra pour localiser l'objet et l'évacuer.

Un majeur protégé a mis un produit qui durcit dans les toilettes ? (Par exemple du plâtre, du pain…)

Dans ce cas là, un débouchage avec furet peut suffire, sinon un hydrocurage peut être nécessaire.

Lavabo/douche

Dans la salle de bain, les cheveux qui se concentrent dans le siphon du lavabo ou de la douche causent souvent des problèmes d’évacuation.

Pour éviter cela, il est important de veiller à ce que le siphon soit nettoyé régulièrement pour éliminer les cheveux accumulés dans celui-ci.

Évier

Dans la cuisine, les déchets alimentaires et les graisses peuvent facilement causer des obstructions dans l'évier.

Dans la pratique, il est toujours conseillé de jeter les restes de nourriture dans une poubelle plutôt que de les laver dans l'évier.

Les graisses et les huiles doivent également être évitées autant que possible, car elles peuvent se solidifier dans les canalisations et provoquer des blocages.

Si vous vous retrouvez face à cette situation, sachez qu'elle peut souvent être résolue avec un simple débouchage à l'aide d'un furet.

Conclusion

En conclusion, les canalisations bouchées peuvent être une source de stress et de problèmes pour les bénéficiaires que vous accompagnez en tant que MJPM ou aidant professionnel.

Il est important de savoir comment éviter ces problèmes en veillant à ce que les objets inappropriés ne soient pas jetés dans les toilettes, en nettoyant régulièrement les siphons et en évitant de jeter les restes alimentaires dans l'évier.

Si le problème survient, un débouchage simple avec un furet peut souvent suffire à résoudre la situation.

Dans certains cas, il est nécessaire de réaliser un passage caméra ou un hydrocurage.
